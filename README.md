1️⃣ What is the difference between var, let, and const?
Answer: 
There are some difference between var, let and const.. but the main differences are the following:
'var' is function scoped, 'let' & 'const' are block scoped. can be reassign value of the variable by using 'var' & 'let',  but it's not possible to reassign value of the variable using 'const.' can be redeclare with same variable name using 'var', but not possible redeclare using 'let' & 'const'. "var" is hoisted but shows 'undefined'. "let" & "const" are also hoisted but have TDZ.
